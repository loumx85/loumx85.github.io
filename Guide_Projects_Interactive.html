🚀 Ouvrir ChatGPT

1️⃣ Activité 1: Créer votre Project

⏱ 5 minutes
1 Ouvrir ChatGPT

Rendez-vous sur chat.openai.com et connectez-vous

2 Accéder aux Projects
  1. Cliquez sur votre nom (menu latéral gauche, en haut)
  2. Dans le menu déroulant, sélectionnez "Projects"
3 Créer un nouveau Project

Cliquez sur "+ New Project" (bouton en haut à droite)

4 Nommer votre Project

Choisissez un nom clair et explicite :

🔧 Mécanique Auto

"Mécanique Auto LP 2024-25"

🍽 Hôtellerie

"Cuisine & Service - Bac Pro"

💼 Commerce

"Vente Conseil - CAP"

💻 Tertiaire

"Bureautique & Communication"

5 Ajouter les instructions de base

Cliquez sur "Instructions" puis copiez-collez ce prompt :

Tu es un assistant pédagogique spécialisé en [VOTRE DISCIPLINE]. Tu connais le contexte du lycée professionnel et tu adaptes tes réponses aux élèves de niveau CAP/Bac Pro. Tu fournis des exemples concrets et applicables en atelier/classe. Tu utilises un ton professionnel mais accessible.
💡 Important : Remplacez [VOTRE DISCIPLINE] par votre matière !

✅ Vérification Activité 1

2️⃣ Activité 2: Uploader vos fichiers

⏱ 10 minutes
🎯 Objectif : Enrichir votre Project avec VOS documents de référence pour que l'IA puisse s'en servir

Quels fichiers uploader ?

🔧 Mécanique Auto

  • Manuels techniques
  • Fiches de diagnostic
  • Protocoles de sécurité
  • Schémas électriques

🍽 Hôtellerie

  • Fiches techniques recettes
  • Protocoles HACCP
  • Fiches de service
  • Cartes de vins

💼 Commerce

  • Argumentaires produits
  • Études de cas clients
  • Techniques de vente
  • Fiches produits

💻 Tertiaire

  • Modèles de documents
  • Procédures administratives
  • Supports de communication
  • Normes de présentation
1 Ouvrir votre Project

Cliquez sur le nom de votre Project dans la liste

2 Accéder à la section Files

Dans le menu du Project, cherchez "Files" ou "Add files"

3 Uploader vos fichiers
  1. Cliquez sur "Upload files" ou "+ Add files"
  2. Sélectionnez 2-3 fichiers sur votre ordinateur
  3. Attendez la fin du chargement (barre de progression)
⚠️ Limite version gratuite : 10 fichiers maximum

💡 Formats acceptés

  • ✅ PDF (recommandé)
  • ✅ Word (.docx)
  • ✅ Images (.jpg, .png)
  • ✅ Excel (.xlsx)
  • ✅ Texte (.txt)

3️⃣ Activité 3: Instructions avancées

⏱ 10 minutes
🎯 Objectif : Personnaliser le comportement de l'IA pour qu'elle réponde exactement comme vous le voulez
1 Accéder aux instructions

Dans votre Project, cliquez sur "Instructions"

2 Remplacer par le template avancé

Effacez les instructions actuelles et copiez-collez ce template :

INSTRUCTIONS POUR MON ASSISTANT [VOTRE DISCIPLINE] 1. TON → Accessible, bienveillant, pédagogique → Adapté à des enseignants de LP 2. PUBLIC CIBLE → Élèves de CAP et Bac Pro en [discipline] → Contexte : LP Mahina, Polynésie française 3. FORMAT DE RÉPONSE → Toujours structurer en étapes numérotées → Donner des exemples concrets applicables en atelier/classe → Proposer 3 niveaux : débutant / intermédiaire / avancé 4. CONTRAINTES → Citer les documents uploadés quand tu t'en sers → Signaler si une procédure nécessite du matériel spécifique → Adapter le vocabulaire technique au niveau élève → Intégrer des exemples du contexte tahitien quand pertinent 5. OBJECTIF PRINCIPAL → Aider à préparer des cours pratiques et motivants → Créer des supports pédagogiques de qualité → Gagner du temps sur les tâches répétitives
3 Personnaliser selon votre discipline

🔧 Mécanique Auto

CONTRAINTES SPÉCIFIQUES : → Toujours mentionner les EPI nécessaires → Citer les normes de sécurité → Indiquer outils/équipements requis → Préciser le type de véhicule → Donner les couples de serrage

🍽 Hôtellerie

CONTRAINTES SPÉCIFIQUES : → Respecter protocoles HACCP → Indiquer températures → Préciser quantités et coûts → Mentionner les allergènes → Adapter au contexte tahitien

💼 Commerce

CONTRAINTES SPÉCIFIQUES : → Utiliser méthode SONCAS → Structurer en étapes de vente → Inclure objections clients réalistes → Adapter au contexte tahitien → Proposer variantes B2B et B2C

💻 Tertiaire

CONTRAINTES SPÉCIFIQUES : → Respecter normes de présentation → Indiquer logiciels/outils → Codes administratifs → Formules de politesse tahitiennes → Niveau de formalisme requis
4 Sauvegarder

Cliquez sur "Save" pour activer vos instructions

✅ Vérification Activité 3

4️⃣ Activité 4: Tester votre Project

⏱ 10 minutes
🎯 Objectif : Vérifier que votre Project fonctionne comme prévu avec des cas d'usage réels

Prompts de test par discipline

🔧 Mécanique Auto

Test 1: Activité pratique
En te basant sur le manuel technique que je t'ai fourni, explique-moi la procédure de diagnostic d'un problème de freinage sur un véhicule récent. Format : Fiche d'activité pour TP de 2h avec mes CAP 1ère année. Inclus : - Objectif pédagogique - Matériel nécessaire - EPI obligatoires - Déroulé en étapes numérotées - Critères d'évaluation
Test 2: Grille d'évaluation
Crée une grille d'évaluation pratique pour un TP de changement de plaquettes de frein. Public : CAP 2e année Format : 5 critères observables avec barème sur 20 points Inclus les points de sécurité obligatoires

🍽 Hôtellerie-Restauration

Test 1: Plan de nettoyage
En respectant les protocoles HACCP que je t'ai fournis, crée-moi un plan de nettoyage pour une cuisine professionnelle. Format : Tableau avec zones, fréquences et produits adaptés. Public : CAP Cuisine 1ère année.
Test 2: Fiche technique recette
Crée une fiche technique recette pour un plat tahitien adapté à un service restaurant. Inclus : - Liste ingrédients avec coûts - Étapes de préparation numérotées - Temps de cuisson et températures - Dressage et présentation - Points HACCP critiques

💼 Commerce/Vente

Test 1: Argumentaire de vente
En t'inspirant des études de cas clients que je t'ai fournies, propose-moi un argumentaire de vente pour un produit haut de gamme. Public : Bac Pro commerce en situation d'examen Méthode : SONCAS Format : Dialogue vendeur-client avec objections
Test 2: Situations de réclamation
Génère 5 situations de réclamation client avec niveaux de difficulté croissants. Public : CAP vente Pour chaque situation : problème + solution attendue + critères d'évaluation

💻 Tertiaire

Test 1: Modèle de courrier
Crée un modèle de courrier professionnel de réclamation client. Public : CAP tertiaire Format : Structure avec zones à compléter Inclus les formules de politesse adaptées au contexte polynésien
Test 2: Exercices Excel
Propose une série de 5 exercices progressifs sur Excel pour apprendre les formules de base (SOMME, MOYENNE, SI). Public : Bac Pro tertiaire 1ère année Contexte : Gestion d'un stock de fournitures

✅ Ce que vous devez observer

  • L'IA cite vos documents uploadés
  • L'IA respecte le format demandé
  • L'IA adapte le vocabulaire au niveau LP
  • L'IA donne des exemples concrets
⚠️ Si ce n'est pas le cas : Retournez dans "Instructions" et ajustez. Par exemple, ajoutez :
IMPÉRATIF : → Tu DOIS TOUJOURS citer les documents uploadés que tu utilises → Tu DOIS TOUJOURS structurer tes réponses avec des numéros → Tu DOIS TOUJOURS donner au moins 2 exemples concrets
