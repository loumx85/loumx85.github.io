🎯 Objectifs du Parcours

À la suite de ce parcours, vous serez capable de :

  • Créer une présentation professionnelle enrichie

1 ChatGPT - Générer le contenu (15 min)

Objectif : Créer un document structuré de 600-800 mots qui servira de base à votre présentation.

📝 Prompt à utiliser

PROMPT GÉNÉRIQUE
Tu es expert en pédagogie pour lycée professionnel en [VOTRE DISCIPLINE].

Crée-moi un document structuré pour présenter [VOTRE SUJET] incluant :

1. Introduction accrocheuse (3 lignes)
2. [3-5 POINTS CLÉS selon votre sujet]
3. Exemples concrets adaptés au LP
4. Conclusion avec appel à l'action

Format : structure claire avec titres H1, H2, H3
Ton : professionnel mais accessible
Longueur : 600-800 mots
⚠️ PERSONNALISEZ :
  • Remplacez [VOTRE DISCIPLINE] : maths, français, mécanique, hôtellerie, commerce...
  • Remplacez [VOTRE SUJET] : présentation filière, JPO, cours sur X, sensibilisation Y...
  • Adaptez les points clés selon votre besoin spécifique

💡 Exemples concrets

Exemple 1 : Mécanique Auto (JPO) 
Tu es expert en pédagogie pour lycée professionnel en MÉCANIQUE AUTO.

Crée-moi un document structuré pour présenter LA FILIÈRE MAINTENANCE VÉHICULES lors des JPO incluant :

1. Introduction accrocheuse (3 lignes)
2. Les 4 métiers principaux après le bac
3. Compétences développées pendant la formation
4. Débouchés locaux en Polynésie
5. Conclusion avec appel à l'action

Format : structure claire avec titres H1, H2, H3
Ton : professionnel mais accessible
Longueur : 600-800 mots
Exemple 2 : Hôtellerie-Restauration (Présentation filière) 
Tu es expert en pédagogie pour lycée professionnel en HÔTELLERIE-RESTAURATION.

Crée-moi un document structuré pour présenter LES DÉBOUCHÉS EN HÔTELLERIE EN POLYNÉSIE incluant :

1. Introduction accrocheuse (3 lignes)
2. Les 5 secteurs qui recrutent localement
3. Compétences recherchées par les employeurs
4. Salaires et évolution de carrière
5. Témoignages fictifs de professionnels
6. Conclusion avec appel à l'action

Format : structure claire avec titres H1, H2, H3
Ton : professionnel mais accessible
Longueur : 600-800 mots
Exemple 3 : Commerce (Cours) 
Tu es expert en pédagogie pour lycée professionnel en COMMERCE.

Crée-moi un document structuré pour un cours sur LES TECHNIQUES DE VENTE incluant :

1. Introduction accrocheuse (3 lignes)
2. Les 4 étapes de la vente (AIDA ou autre)
3. Techniques de questionnement client
4. Traitement des objections
5. Exemples concrets en magasin polynésien
6. Conclusion avec appel à l'action

Format : structure claire avec titres H1, H2, H3
Ton : pédagogique et motivant
Longueur : 600-800 mots
✅ Résultat attendu : Un document de 600-800 mots, bien structuré avec des titres clairs, prêt à utiliser pour votre présentation.

2 DALL-E - Créer les visuels (15 min)

Objectif : Générer 3-4 images uniques et professionnelles pour illustrer votre présentation.

🎨 Prompt à utiliser

📍 Important : Utilisez le MÊME CHAT que l'étape 1. Continuez simplement la conversation.

PROMPT GÉNÉRIQUE IMAGES
Génère 3 images pour illustrer ce document :

1. Image de couverture : [DESCRIPTION VISUELLE DE VOTRE THÈME]
   Style : moderne, professionnel, lumineux

2. Illustration concept clé : [VOTRE CONCEPT PRINCIPAL]
   Style : infographie simple et colorée

3. Exemple concret : [SCÈNE RÉELLE DE VOTRE DOMAINE]
   Style : réaliste, contexte polynésien si possible

💡 Exemples concrets

Exemple 1 : Mécanique Auto 
Génère 3 images pour illustrer ce document :

1. Image de couverture : Atelier de mécanique automobile moderne dans un lycée professionnel, avec des élèves en bleu de travail qui travaillent sur des véhicules récents
   Style : moderne, professionnel, lumineux

2. Illustration concept clé : Schéma simple montrant les 4 grands domaines de compétences en maintenance véhicules (mécanique, électricité, carrosserie, diagnostic)
   Style : infographie simple et colorée

3. Exemple concret : Jeune mécanicien polynésien souriant qui fait un diagnostic électronique sur une voiture dans un garage local
   Style : réaliste, contexte polynésien
Exemple 2 : Hôtellerie-Restauration 
Génère 3 images pour illustrer ce document :

1. Image de couverture : Cuisine professionnelle de lycée hôtelier en Polynésie, avec des élèves en toque qui préparent des plats, ambiance dynamique
   Style : moderne, professionnel, lumineux

2. Illustration concept clé : Pyramide des métiers de l'hôtellerie-restauration avec 5 niveaux (de commis à chef)
   Style : infographie simple et colorée

3. Exemple concret : Service en salle dans un restaurant haut de gamme polynésien, serveur professionnel avec vue sur lagon
   Style : réaliste, contexte polynésien
Exemple 3 : Commerce 
Génère 3 images pour illustrer ce document :

1. Image de couverture : Boutique moderne en Polynésie avec vendeur qui accueille un client, ambiance chaleureuse et professionnelle
   Style : moderne, professionnel, lumineux

2. Illustration concept clé : Les 4 étapes de la méthode AIDA (Attention, Intérêt, Désir, Action) sous forme de funnel coloré
   Style : infographie simple et colorée

3. Exemple concret : Jeune vendeuse polynésienne souriante qui conseille une cliente dans un magasin local, interaction authentique
   Style : réaliste, contexte polynésien
💡 Astuces :
  • Téléchargez IMMÉDIATEMENT les 3 images après génération (clic droit > Enregistrer)
  • Si une image ne vous plaît pas, redemandez : "Peux-tu régénérer l'image 2 avec plus de détails ?"
  • Ajoutez "style professionnel, moderne, réaliste" si le résultat est trop abstrait
⚠️ Si DALL-E ne génère pas ce que vous voulez :
  • Soyez plus descriptif dans vos demandes
  • Essayez 2-3 fois, gardez la meilleure version
  • Vous pouvez toujours ajuster dans Gamma ensuite
✅ Résultat attendu : 3 images haute qualité téléchargées sur votre ordinateur, prêtes à être intégrées dans Gamma.

3 Gamma - Assembler la présentation (20 min)

Objectif : Transformer votre texte en présentation professionnelle de 8-10 slides avec vos visuels.

📊 Marche à suivre

  1. Aller sur https://gamma.app (connexion Google)
  2. Cliquer sur "Paste to create" ou "Coller pour créer"
  3. Copier-coller tout le texte généré par ChatGPT (étape 1)
  4. Choisir un template (prenez celui qui vous plaît visuellement)
  5. Attendre 30 secondes → Présentation automatiquement générée ✨
  6. Ajouter vos images DALL-E :
    • Cliquer sur une slide
    • Cliquer sur "Replace image" ou "Add image"
    • Upload vos 3 images
    • Répartir sur 3 slides différentes
  7. Personnaliser (optionnel) :
    • Changer les couleurs si besoin
    • Ajuster les titres
    • Ajouter une slide de conclusion
  8. Mode Présentation pour vérifier le résultat final
💡 Astuces Gamma :
  • Templates : Le premier qui vous plaît est souvent le meilleur. Pas besoin de passer 10 minutes à comparer.
  • Images : Glisser-déposer fonctionne aussi bien que "Replace image"
  • Modification : Cliquez sur n'importe quel texte pour l'éditer directement
  • Partage : Gamma génère automatiquement un lien partageable
⚠️ Si Gamma ne vous plaît pas :
  • Essayez un autre template (bouton "Change theme")
  • Ou modifiez manuellement les slides qui ne vous conviennent pas
  • Gamma permet une personnalisation complète
✅ Résultat attendu : Présentation de 8-10 slides, visuellement attractive, avec vos 3 images intégrées, prête à présenter.

4 NotebookLM - Podcast bonus (10 min)

Objectif : Transformer votre contenu en podcast de 5-8 minutes avec 2 voix IA qui discutent.

🌟 C'est l'outil STAR de la formation !
Le résultat va vous impressionner : 2 voix IA naturelles vont discuter de votre contenu comme dans une émission radio.

🎙️ Marche à suivre

  1. Aller sur https://notebooklm.google.com
  2. Créer un nouveau notebook (bouton "+ New")
  3. Copier votre texte ChatGPT dans un Google Doc
    • Ou copier-coller directement dans NotebookLM
  4. Uploader ce Google Doc dans NotebookLM
    • Cliquer sur "+" → "Google Doc" → Coller le lien
    • Ou cliquer sur "+" → "Paste text" → Coller le texte directement
  5. Cliquer sur "Audio Overview" (icône 🎙️) en haut
  6. Cliquer sur "Generate"
  7. Attendre 3-5 minutes (ne fermez pas la page !)
  8. Le podcast est généré ! Cliquez sur PLAY 🎧
  9. Télécharger : Cliquer sur "..." (3 points) → "Download"
🎯 Ce que vous allez entendre :
  • 2 voix IA (une masculine, une féminine) très naturelles
  • Elles discutent de votre contenu comme dans une émission radio
  • Elles reformulent, ajoutent des transitions, posent des questions
  • Durée : 5-8 minutes environ
  • Qualité audio professionnelle
💡 Utilisations possibles de votre podcast :
  • Pour vos élèves : Envoyer via Pronote, écoute en voiture ou pendant le sport
  • Pour vous : Réviser le contenu en préparant vos cours
  • Pour les JPO : Diffuser en fond sonore pendant les visites
  • Accessibilité : Parfait pour élèves DYS ou malvoyants
⚠️ Si le podcast est trop court :
  • Votre texte source était probablement trop court (moins de 400 mots)
  • Solution : Demandez à ChatGPT de développer davantage
  • Plus vous donnez de matière à NotebookLM, plus le podcast sera riche
✅ Résultat attendu : Podcast MP3 de 5-8 minutes, format radio naturel, prêt à partager avec vos élèves ou collègues.

💡 Astuces Pro

Si vous bloquez sur ChatGPT :
  • Soyez plus précis dans votre demande
  • Donnez un exemple concret de ce que vous voulez
  • Relancez : "Peux-tu rendre ça plus concret pour des élèves de LP ?"
Si DALL-E ne génère pas ce que vous voulez :
  • Reformulez en étant plus descriptif
  • Ajoutez "style professionnel" ou "style moderne"
  • Essayez 2-3 fois, gardez la meilleure image
Si Gamma ne vous plaît pas :
  • Essayez un autre template
  • Ou utilisez votre présentation comme base et modifiez manuellement
Gain de temps :
  • Préparez votre prompt ChatGPT AVANT la session
  • Ayez votre sujet clair en tête
  • Téléchargez les images DALL-E immédiatement après génération
