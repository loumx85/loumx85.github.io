🎯 Objectifs du Parcours

À la suite de ce parcours, vous serez capable de :

  • Créer un script vidéo percutant de 60-90 secondes
  • Générer des visuels adaptés à votre scénario
  • Produire une voix-off professionnelle avec l'IA

📌 Pour qui ? Sensibilisation métier, capsules pédagogiques, révisions, motivation élèves

🎁 Résultat final : Vidéo 60-90 secondes avec voix-off professionnelle et sous-titres automatiques

1 ChatGPT - Créer le script (10 min)

Objectif : Créer un script de vidéo de 90 secondes maximum, découpé en séquences claires.

💡 Astuce : 1 minute de narration = environ 150 mots. Donc 90 secondes = 225 mots maximum.

📝 Prompt à utiliser

PROMPT GÉNÉRIQUE SCRIPT VIDÉO
Tu es scénariste de vidéos pédagogiques courtes pour lycée professionnel.

Crée un script de vidéo de 90 secondes maximum sur [VOTRE SUJET] :

Structure :
- Accroche (10 sec / 25 mots)
- 3 points clés (60 sec / 150 mots)
- Conclusion/Appel à l'action (20 sec / 50 mots)

Public : Élèves de LP en [VOTRE FILIÈRE]
Ton : Dynamique, motivant, concret
Format : Numéroter chaque séquence de 1 à 5

Total : 225 mots maximum (= 90 secondes de narration)
⚠️ PERSONNALISEZ :
  • Remplacez [VOTRE SUJET] par votre thème exact
  • Remplacez [VOTRE FILIÈRE] par votre spécialité
  • Adaptez le ton selon votre objectif (sérieux, motivant, informatif...)

💡 Exemples concrets

Exemple 1 : Sécurité en atelier mécanique 
Tu es scénariste de vidéos pédagogiques courtes pour lycée professionnel.

Crée un script de vidéo de 90 secondes maximum sur LA SÉCURITÉ EN ATELIER DE MÉCANIQUE :

Structure :
- Accroche (10 sec / 25 mots)
- 3 règles de sécurité essentielles (60 sec / 150 mots)
- Conclusion/Appel à l'action (20 sec / 50 mots)

Public : Élèves de LP en Maintenance Véhicules
Ton : Dynamique, sérieux mais accessible, concret
Format : Numéroter chaque séquence de 1 à 5

Total : 225 mots maximum (= 90 secondes de narration)
Exemple 2 : Motivation avant stage (Hôtellerie) 
Tu es scénariste de vidéos pédagogiques courtes pour lycée professionnel.

Crée un script de vidéo de 90 secondes maximum sur RÉUSSIR SON STAGE EN HÔTELLERIE :

Structure :
- Accroche (10 sec / 25 mots)
- 3 clés de succès en stage (60 sec / 150 mots)
- Conclusion motivante (20 sec / 50 mots)

Public : Élèves de LP en Hôtellerie-Restauration avant leur PFMP
Ton : Motivant, bienveillant, encourageant
Format : Numéroter chaque séquence de 1 à 5

Total : 225 mots maximum (= 90 secondes de narration)
Exemple 3 : Présentation métier (Commerce) 
Tu es scénariste de vidéos pédagogiques courtes pour lycée professionnel.

Crée un script de vidéo de 90 secondes maximum sur LE MÉTIER DE VENDEUR EN MAGASIN :

Structure :
- Accroche (10 sec / 25 mots)
- 3 aspects du métier (missions, compétences, évolution) (60 sec / 150 mots)
- Conclusion avec appel à l'action (20 sec / 50 mots)

Public : Élèves de 3ème pour orientation
Ton : Dynamique, positif, valorisant le métier
Format : Numéroter chaque séquence de 1 à 5

Total : 225 mots maximum (= 90 secondes de narration)
💡 Vérifiez votre script :
  • Le texte fait bien 200-250 mots (pas plus !)
  • Chaque séquence est numérotée (1 à 5)
  • Le ton est adapté à votre public
  • Le message est clair et percutant
✅ Résultat attendu : Script de 200-250 mots, découpé en 5 séquences numérotées, prêt à être narré.

2 DALL-E - Créer les visuels vidéo (15 min)

Objectif : Générer 4 images cohérentes qui illustreront chaque partie de votre vidéo.

📍 Important : Utilisez le MÊME CHAT que l'étape 1. Continuez la conversation.

🎨 Prompt à utiliser

PROMPT GÉNÉRIQUE VISUELS VIDÉO
Génère 4 images pour ma vidéo sur [VOTRE SUJET] :

Image 1 (Accroche) : [VISUEL IMPACTANT D'OUVERTURE]
Style : Attention-grabbing, dynamique

Image 2 (Point clé 1) : [ILLUSTRATION 1ER POINT]
Style : Clair, pédagogique

Image 3 (Point clé 2) : [ILLUSTRATION 2ÈME POINT]
Style : Clair, pédagogique

Image 4 (Conclusion) : [VISUEL POSITIF/MOTIVANT]
Style : Inspirant, professionnel

Note : Toutes les images doivent avoir une cohérence visuelle (même palette de couleurs, même style)

💡 Exemples concrets

Exemple 1 : Sécurité en atelier 
Génère 4 images pour ma vidéo sur LA SÉCURITÉ EN ATELIER :

Image 1 (Accroche) : Atelier de mécanique avec un panneau "DANGER" bien visible, ambiance sérieuse mais moderne
Style : Attention-grabbing, dynamique

Image 2 (Équipements) : Jeune mécanicien qui porte correctement tous ses EPI (lunettes, gants, chaussures de sécurité), avec check marks verts
Style : Clair, pédagogique, infographie

Image 3 (Zone de travail) : Atelier bien rangé vs atelier en désordre (split screen avant/après)
Style : Clair, pédagogique, comparatif

Image 4 (Conclusion) : Équipe de jeunes mécaniciens souriants, pouce levé, dans un atelier sécurisé
Style : Inspirant, professionnel, positif

Note : Palette de couleurs bleu et orange, style moderne et professionnel
Exemple 2 : Motivation stage hôtellerie 
Génère 4 images pour ma vidéo sur RÉUSSIR SON STAGE EN HÔTELLERIE :

Image 1 (Accroche) : Élève en tenue professionnelle d'hôtellerie devant l'entrée d'un hôtel élégant, regard déterminé
Style : Attention-grabbing, motivant

Image 2 (Ponctualité) : Réveil qui sonne à 6h du matin, main qui l'arrête avec énergie
Style : Dynamique, clair

Image 3 (Attitude positive) : Interaction souriante entre stagiaire et chef de cuisine dans une cuisine pro
Style : Clair, bienveillant, professionnel

Image 4 (Conclusion) : Stagiaire qui reçoit des félicitations de son tuteur, certificat de stage en main, sourire fier
Style : Inspirant, positif, réussite

Note : Palette chaleureuse (blanc, doré, vert menthe), style réaliste et valorisant
Exemple 3 : Présentation métier vendeur 
Génère 4 images pour ma vidéo sur LE MÉTIER DE VENDEUR :

Image 1 (Accroche) : Vendeuse dynamique en magasin moderne qui accueille un client avec un sourire
Style : Attention-grabbing, énergique

Image 2 (Missions) : Split screen montrant 3 scènes : conseil client, réassort rayon, caisse
Style : Infographie claire, moderne

Image 3 (Compétences) : Vendeur en train d'expliquer un produit à un client, bulles de dialogue avec mots-clés (écoute, conseil)
Style : Pédagogique, illustratif

Image 4 (Évolution) : Parcours de carrière visualisé : vendeur → responsable rayon → directeur magasin (flèche ascendante)
Style : Inspirant, motivant, schéma clair

Note : Couleurs vives et modernes (bleu, rose, jaune), style cartoon professionnel
💡 Astuces visuelles :
  • Cohérence : Demandez la même palette de couleurs pour toutes les images
  • Téléchargement : Sauvegardez les 4 images immédiatement après génération
  • Qualité : Si une image est floue, redemandez-la avec plus de détails
✅ Résultat attendu : 4 images cohérentes, haute qualité, téléchargées sur votre ordinateur, prêtes pour le montage.

3 ElevenLabs - Créer la voix-off (10 min)

Objectif : Transformer votre script en narration audio professionnelle avec une voix IA.

🎙️ Marche à suivre

  1. Aller sur https://elevenlabs.io
  2. S'inscrire (gratuit - 10 000 caractères/mois suffisent largement)
  3. Cliquer sur "Text to Speech" dans le menu
  4. Copier votre script ChatGPT
    • ⚠️ UNIQUEMENT le texte à narrer, pas les numéros de séquence ni les indications
  5. Choisir une voix française :
    • "Antoine" : Voix masculine sérieuse et professionnelle
    • "Charlotte" : Voix féminine douce et claire
    • "Clyde" : Voix masculine dynamique
    • 💡 Testez plusieurs voix avec 1 phrase pour choisir
  6. Générer (bouton "Generate" - prend 30 secondes)
  7. Écouter le résultat
    • Si ça ne vous plaît pas, changez de voix et régénérez
  8. Télécharger le fichier MP3 (icône téléchargement)
💡 Conseils voix-off :
  • Ponctuation : Ajoutez des virgules pour créer des pauses naturelles
  • Ton : Les voix s'adaptent au contexte (! pour enthousiasme, ... pour suspense)
  • Test : Écoutez TOUJOURS avant de valider
  • Gratuit : 10 000 caractères/mois = environ 15 vidéos de 90 sec
⚠️ Alternative si ElevenLabs ne fonctionne pas :
  • Utilisez votre propre voix (enregistrement smartphone)
  • Ou enregistrez directement dans CapCut à l'étape suivante
✅ Résultat attendu : Fichier audio MP3 de 90 secondes, voix professionnelle, prêt à intégrer dans CapCut.

4 CapCut - Monter la vidéo (25 min)

Objectif : Assembler images, voix-off et sous-titres automatiques en une vidéo finale professionnelle.

📍 Important : CapCut peut sembler complexe au début, mais suivez les étapes une par une et tout ira bien !

🎬 Marche à suivre détaillée

A. PRÉPARATION

  1. Aller sur https://www.capcut.com (version web)
  2. Se connecter (compte Google fonctionne)
  3. Créer un nouveau projet (bouton "+ New video")

B. IMPORTER VOS FICHIERS

  1. Cliquer sur "Upload" (coin supérieur gauche)
  2. Importer :
    • Vos 4 images DALL-E
    • Votre fichier audio MP3 (voix-off)
  3. Attendre que tous les fichiers soient uploadés (quelques secondes)

C. ASSEMBLER LA VIDÉO

  1. AUDIO : Glisser votre MP3 sur la timeline (barre du bas)
    • L'audio détermine la durée totale de votre vidéo
  2. IMAGES : Glisser vos 4 images EN SÉQUENCE sur la timeline
    • Image 1 (accroche) : 0-20 secondes
    • Image 2 (point 1) : 20-45 secondes
    • Image 3 (point 2) : 45-70 secondes
    • Image 4 (conclusion) : 70-90 secondes
    • 💡 Ajustez la durée de chaque image en tirant les bords

D. SOUS-TITRES AUTOMATIQUES ⭐ (LA MAGIE !)

  1. Cliquer sur "Captions" (menu gauche)
  2. Sélectionner "Auto captions"
  3. Langue : Choisir "Français"
  4. Cliquer "Generate" → Attendre 30 secondes
  5. RÉSULTAT : Sous-titres synchronisés automatiquement ! ✨
  6. Personnaliser (optionnel) :
    • Changer la police
    • Modifier la couleur de fond
    • Ajuster la taille

E. TRANSITIONS (OPTIONNEL - 5 min)

  1. Cliquer entre 2 images sur la timeline
  2. Cliquer sur "Transition" (menu du haut)
  3. Choisir "Dissolve" ou "Fade" (les plus professionnelles)
  4. Durée : 0.5 secondes
  5. Répéter pour les autres transitions

F. TEXTE (OPTIONNEL - 5 min)

  1. Ajouter un titre au début :
    • Cliquer "Text" → "Default text"
    • Écrire votre titre
    • Placer sur la première image (3-5 secondes)
  2. Ajouter votre nom à la fin (optionnel)

G. MUSIQUE DE FOND (OPTIONNEL - 3 min)

  1. Cliquer "Audio" → "Music"
  2. Chercher "upbeat" ou "corporate" ou "motivational"
  3. Écouter et choisir une musique
  4. Glisser sur la timeline en-dessous de votre voix
  5. IMPORTANT : Baisser le volume de la musique à 20-30%
    • Cliquer sur la piste musicale → Ajuster le volume
    • La voix doit être prioritaire !

H. PRÉVISUALISER ET EXPORTER

  1. Cliquer sur PLAY (barre d'espace) pour prévisualiser
  2. Vérifier :
    • Les sous-titres sont bien synchronisés
    • Les transitions sont fluides
    • Le son est bon (voix audible, musique en fond)
  3. Si OK : Cliquer "Export" (coin supérieur droit)
  4. Qualité : Choisir 1080p (Full HD)
  5. Télécharger → Attendre 1-2 minutes
  6. TERMINÉ ! Votre vidéo est prête 🎉
💡 Astuces CapCut :
  • Zoom timeline : Molette souris pour voir les détails
  • Annuler : Ctrl+Z (comme partout)
  • Lecture : Barre d'espace pour play/pause
  • Sauvegarde : CapCut sauvegarde automatiquement
⚠️ Si CapCut rame :
  • Fermez les autres onglets de votre navigateur
  • Travaillez en qualité "Draft" puis exportez en 1080p à la fin
  • Si vraiment trop lent : utilisez l'application desktop (plus rapide)
✅ Résultat attendu : Vidéo MP4 de 60-90 secondes, avec voix-off, sous-titres automatiques, transitions fluides, prête à partager !

  • Concentrez-vous sur l'essentiel

  • Ça reste professionnel avec une bonne diction !
